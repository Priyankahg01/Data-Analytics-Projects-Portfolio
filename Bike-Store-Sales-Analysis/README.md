# Bike Store Sales Analysis

## Project Overview

This project analyzes bike store sales data using Python and Jupyter Notebook. The objective is to explore the dataset, understand customer and sales patterns, analyze revenue and profit, and generate meaningful business insights through data analysis and visualization.

## Data Exploration & Analysis

The dataset was explored using statistical summaries and Pandas operations to understand its structure, characteristics, and numerical variables.

The analysis includes:
- Data exploration and descriptive statistics
- Unit Cost analysis using mean, median, box plots, density plots, and histograms
- Customer age group analysis
- Correlation analysis between numerical variables
- Revenue and profit analysis
- Analysis of relationships between customer age, revenue, profit, and calculated cost
- Calculation and validation of cost, revenue, and revenue-per-age metrics
- Conditional filtering and data manipulation

## Data Visualization

Various visualizations were created to identify patterns and relationships in the data, including:
- Histograms
- Density plots
- Box plots
- Bar charts
- Pie charts
- Scatter plots
- Correlation matrix
